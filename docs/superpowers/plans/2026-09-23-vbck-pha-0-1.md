# VBCK Pha 0 + Pha 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xác minh các giả định về EMR/ACS mà module Văn bản công khai có QR phụ thuộc (Pha 0), và làm cho
đăng nhập qlbv lấy được `TokenCode` ACS của chính người dùng, có chống dò mật khẩu, làm mới session và fallback
khi ACS API không phản hồi (Pha 1).

**Architecture:** Pha 0 là tài liệu câu hỏi gửi nhà cung cấp + một script spike chạy trên nhánh riêng

trong `App\Services\Auth`: `MatKhauAcs` (so hash cũ), `AcsAuthenticator` (gọi API ACS, phân loại lỗi),
`AcsSessionToken` (giữ token trong session, khóa theo thời gian không thao tác), `DangNhapService` (quyết
định đăng nhập/fallback). `LoginController` chỉ còn throttle, gọi service, `Auth::login`, regenerate session.

**Tech Stack:** Laravel 5.5.50, PHP 7.4, PHPUnit 6.5.14, Guzzle 6.5.8, Oracle `ACS_RS` (bảng `acs_user`).

**Spec:** `docs/superpowers/specs/2026-09-22-van-ban-cong-khai-qr-design.md` — mục 5 (đăng nhập), 13 (Pha 0),
14 (ảnh hưởng). Pha 2–4 **không** thuộc kế hoạch này: sẽ lập kế hoạch riêng sau khi có kết quả Pha 0.

## Global Constraints

- `App\CustomUser` = bảng `acs_user` trên connection `ACS_RS`; qlbv không có bảng user riêng.
- Hash mật khẩu hiện hành: `hash('sha512', $password . '!@#$%^&*())(*&^%$#@!')`, so bằng `hash_equals` với cột `password`; user phải `is_active = 1`; input tên `email` chứa loginname (so `LOWER(loginname)`).
- Cờ `auth.acs_enabled` mặc định `false`. `false` → hành vi đăng nhập như cũ (cộng throttle + regenerate).
- ACS: `organization.login_acs.login_url`, `organization.login_acs.application_code`; GET, header `Authorization: Basic base64("{app}:{loginname}:{password}")`; phản hồi `{Success, Data{TokenCode, ExpireTime, ...}}`.
- ACS sai thông tin → **không** so hash. ACS không phản hồi → fallback so hash, đăng nhập **không có token**, flash cảnh báo.
- Throttle: 5 lần sai/phút theo `loginname|IP`, kiểm trước mọi truy vấn/lời gọi ACS.
- Token trong session: mã hóa `Crypt`, trừ hao 5 phút trước `ExpireTime`, khóa sau `vbck.sign_idle_minutes` (15) phút không thao tác.
- Không ghi mật khẩu, header Basic, `TokenCode` vào log hay thông điệp ngoại lệ.
- Test: **cấm `RefreshDatabase`/`DatabaseMigrations`**; Unit test `setUp()` không có `: void`; dùng `assertContains` cho chuỗi (PHPUnit 6.5); không mock bằng Mockery lớp có return type — dùng lớp giả kế thừa; test không được gọi ACS/EMR thật.
- Gate test của repo: `vendor/bin/phpunit --testsuite Unit` (suite đầy đủ có nhiễm chéo sẵn; mốc đỏ có chủ đích duy nhất là `CtdtCauHinhTest::gui_len_cong_mac_dinh_tat`).

   AND d.document_type_id IN (/* loại dự kiến */)

require __DIR__ . '/../../vendor/autoload.php';
$app = require __DIR__ . '/../../bootstrap/app.php';
$app->make(Illuminate\Contracts\Console\Kernel::class)->bootstrap();

use GuzzleHttp\Client;

function env_bat_buoc($ten)
{
    $v = getenv($ten);
    if (!$v) {
        fwrite(STDERR, "Thieu bien moi truong $ten\n");
        exit(2);
    }
    return $v;
}

function emr_url()
{
    $url = rtrim(env_bat_buoc('VBCK_SPIKE_EMR_URL'), '/');
    if (strpos($url, '192.168.7.239') !== false) {
        fwrite(STDERR, "TU CHOI: day la EMR THAT. Spike chi chay tren EMR test.\n");
        exit(3);
    }
    return $url;
}

function emr_get($token, $path, array $apiData)
{
    $param = base64_encode(json_encode(['ApiData' => $apiData, 'CommonParam' => ['Start' => 0, 'Limit' => 10]]));
    $r = (new Client())->get(emr_url() . $path, [
        'query' => ['param' => $param],
        'headers' => ['TokenCode' => $token, 'ApplicationCode' => 'EMR'],
        'http_errors' => false, 'timeout' => 60,
    ]);
    return json_decode((string) $r->getBody(), true);
}

function emr_post($token, $path, $apiData)
{
    $r = (new Client())->post(emr_url() . $path, [
        'json' => ['ApiData' => $apiData],
        'headers' => ['TokenCode' => $token, 'ApplicationCode' => 'EMR'],
        'http_errors' => false, 'timeout' => 60,
    ]);
    return json_decode((string) $r->getBody(), true);
}

function in_json($x)
{
    echo json_encode($x, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE), "\n";
}

$lenh = $argv[1] ?? '';

switch ($lenh) {

<?php

namespace App\Services\Auth;

/**
 * Quy uoc bam mat khau cua bang ACS_RS.acs_user, dung nguyen van nhu LoginController::customLogin() cu.
 *
 * Dung cho: dang nhap khi auth.acs_enabled = false, va FALLBACK khi API ACS khong phan hoi.
 * Khong mo loi vao moi: van la dung tai khoan/mat khau trong cung bang ACS.
 */
final class MatKhauAcs
{
    const SALT = '!@#$%^&*())(*&^%$#@!';

    public static function bam($matKhau)
    {
        return hash('sha512', (string) $matKhau . self::SALT);
    }

    public static function khop($matKhau, $hash)
    {
        if (!is_string($hash) || $hash === '') {
            return false;
        }

        return hash_equals($hash, self::bam($matKhau));
    }
}

<?php

namespace App\Services\Auth;

use Carbon\Carbon;
use GuzzleHttp\Client;
use GuzzleHttp\ClientInterface;
use GuzzleHttp\Exception\GuzzleException;

/**
 * Dang nhap ACS bang tai khoan cua CHINH nguoi dung de lay TokenCode (dung cho EMR API).
 *
 * Khac ACSLoginService: lop do dang nhap bang MOT tai khoan dich vu co dinh va cache token dung chung.
 *
 * Phan loai loi la hop dong voi DangNhapService:
 *  - AcsSaiThongTinException: ACS noi ro la sai (401/403, Success !== true) -> KHONG fallback.
 *  - AcsKhongPhanHoiException: khong biet dung sai -> duoc fallback so hash.
 * 404/405... xep vao "khong phan hoi": do la cau hinh URL sai, khong phai nguoi dung go sai mat khau.
 *
 * Thong diep ngoai le KHONG BAO GIO chua mat khau hay header Basic.
 */
class AcsAuthenticator
{
    private $client;
    private $cauHinh;

    public function __construct(ClientInterface $client = null, array $cauHinh = null)
    {
        $this->client = $client;
        $this->cauHinh = $cauHinh;
    }

    public function login($loginname, $password)
    {
        $cauHinh = $this->cauHinh();

        if (empty($cauHinh['login_url'])) {
            throw new AcsKhongPhanHoiException('Chua cau hinh organization.login_acs.login_url');
        }

        $basic = base64_encode($cauHinh['application_code'] . ':' . $loginname . ':' . $password);

        try {
            $response = $this->client()->request('GET', $cauHinh['login_url'], [
                'headers' => ['Authorization' => 'Basic ' . $basic, 'Content-Type' => 'application/json'],
                'timeout' => $cauHinh['timeout'],
                'connect_timeout' => $cauHinh['timeout'],
                'http_errors' => false,
            ]);
        } catch (GuzzleException $e) {
            throw new AcsKhongPhanHoiException('ACS khong phan hoi (' . get_class($e) . ')');
        } catch (\InvalidArgumentException $e) {
            throw new AcsKhongPhanHoiException('URL ACS khong hop le');
        }

        $status = $response->getStatusCode();

        if ($status === 401 || $status === 403) {
            throw new AcsSaiThongTinException('ACS tu choi dang nhap (HTTP ' . $status . ')');
        }

        if ($status >= 400) {
            throw new AcsKhongPhanHoiException('ACS tra HTTP ' . $status);
        }

        $body = json_decode((string) $response->getBody(), true);

        if (!is_array($body) || !array_key_exists('Success', $body)) {
            throw new AcsKhongPhanHoiException('ACS tra du lieu khong hop le');
        }

        if ($body['Success'] !== true) {
            throw new AcsSaiThongTinException('ACS tu choi dang nhap');
        }

        $tokenCode = isset($body['Data']['TokenCode']) ? $body['Data']['TokenCode'] : null;
        $expire = isset($body['Data']['ExpireTime']) ? $body['Data']['ExpireTime'] : null;

        if (!$tokenCode || !$expire) {
            throw new AcsKhongPhanHoiException('ACS thieu TokenCode hoac ExpireTime');
        }

        try {
            $hetHan = Carbon::parse($expire);
        } catch (\Exception $e) {
            throw new AcsKhongPhanHoiException('ExpireTime khong hop le');
        }

        return new AcsToken($tokenCode, $hetHan);
    }

    /** Doc cau hinh LUOI: khoi tao khong bao gio nem, ke ca khi thieu cau hinh. */
    private function cauHinh()
    {
        if ($this->cauHinh === null) {
            $this->cauHinh = [
                'login_url' => config('organization.login_acs.login_url'),
                'application_code' => config('organization.login_acs.application_code', 'HIS'),
                'timeout' => (int) config('auth.acs_timeout', 10),
            ];
        }

        return $this->cauHinh;
    }

    private function client()
    {
        if ($this->client === null) {
            $this->client = new Client();
        }

        return $this->client;
    }
}

<?php

namespace App\Services\Auth;

use Carbon\Carbon;
use Illuminate\Contracts\Encryption\DecryptException;
use Illuminate\Contracts\Session\Session;
use Illuminate\Support\Facades\Crypt;

/**
 * Giu TokenCode ACS cua nguoi dung trong session phia server (ma hoa), de ky khong phai nhap lai mat khau.
 *
 * current() tra null khi: chua co token, token con duoi 5 phut la het han, hoac qua
 * vbck.sign_idle_minutes phut khong thao tac tren man VBCK. Khi do man VBCK bat nhap lai mat khau.
 *
 * touch() CHI gia han khi phien ky con song: khong duoc de viec mo man VBCK lam song lai mot phien da
 * bi khoa do khong thao tac.
 */
class AcsSessionToken
{
    const KHOA_TOKEN = 'vbck_acs_token';
    const KHOA_HOAT_DONG = 'vbck_last_activity';
    const TRU_HAO_GIAY = 300;

    private $session;

    public function __construct(Session $session = null)
    {
        $this->session = $session ?: app('session.store');
    }

    public function store(AcsToken $token)
    {
        $this->session->put(self::KHOA_TOKEN, Crypt::encryptString(json_encode([
            't' => $token->tokenCode(),
            'e' => $token->expireTime()->timestamp,
        ])));
        $this->session->put(self::KHOA_HOAT_DONG, Carbon::now()->timestamp);
    }

    public function current()
    {
        $maHoa = $this->session->get(self::KHOA_TOKEN);

        if (!is_string($maHoa) || $maHoa === '') {
            return null;
        }

        try {
            $du = json_decode(Crypt::decryptString($maHoa), true);
        } catch (DecryptException $e) {
            return null;
        }

        if (!is_array($du) || empty($du['t']) || empty($du['e'])) {
            return null;
        }

        $bayGio = Carbon::now()->timestamp;

        if ((int) $du['e'] - self::TRU_HAO_GIAY <= $bayGio) {
            return null;
        }

        $lanCuoi = (int) $this->session->get(self::KHOA_HOAT_DONG, 0);

        if ($bayGio - $lanCuoi > (int) config('vbck.sign_idle_minutes', 15) * 60) {
            return null;
        }

        return (string) $du['t'];
    }

    public function touch()
    {
        if ($this->current() !== null) {
            $this->session->put(self::KHOA_HOAT_DONG, Carbon::now()->timestamp);
        }
    }

    public function forget()
    {
        $this->session->forget([self::KHOA_TOKEN, self::KHOA_HOAT_DONG]);
    }
}

<?php

namespace App\Services\Auth;

use App\CustomUser;
use Illuminate\Support\Facades\Log;

/**
 * Quyet dinh dang nhap qlbv. User qlbv CHINH LA ACS_RS.acs_user (App\CustomUser).
 *
 *  - acs_enabled = false: so hash sha512 nhu LoginController cu.
 *  - acs_enabled = true : goi API ACS lay TokenCode.
 *      ACS noi sai        -> that bai, KHONG so hash (ACS la nguon quyet dinh).
 *      ACS khong phan hoi -> fallback so hash; dung thi vao KHONG co token, kem canh bao.
 *  - Khong tim thay user active -> that bai, KHONG goi ACS.
 *
 * Throttle va regenerate session nam o LoginController (can Request).
 */
class DangNhapService
{
    const CANH_BAO_ACS_KHONG_PHAN_HOI = 'Hệ thống xác thực ký số tạm thời không phản hồi. Các chức năng khác dùng bình thường; chức năng ký công khai tạm chưa dùng được.';

    private $acs;
    private $timUser;
    private $acsEnabled;

    public function __construct(AcsAuthenticator $acs = null, callable $timUser = null, $acsEnabled = null)
    {
        $this->acs = $acs;
        $this->timUser = $timUser;
        $this->acsEnabled = $acsEnabled;
    }

    public function xacThuc($loginname, $password)
    {
        $user = call_user_func($this->timUser(), $loginname);

        if (!$user) {
            return KetQuaDangNhap::thatBai();
        }

        if (!$this->acsEnabled()) {
            return MatKhauAcs::khop($password, $user->password)
                ? KetQuaDangNhap::thanhCong($user)
                : KetQuaDangNhap::thatBai();
        }

        try {
            return KetQuaDangNhap::thanhCong($user, $this->acs()->login($user->loginname, $password));
        } catch (AcsSaiThongTinException $e) {
            return KetQuaDangNhap::thatBai();
        } catch (AcsKhongPhanHoiException $e) {
            Log::warning('ACS khong phan hoi khi dang nhap, fallback so hash', [
                'loginname' => $user->loginname,
                'ly_do' => $e->getMessage(),
            ]);

            return MatKhauAcs::khop($password, $user->password)
                ? KetQuaDangNhap::thanhCong($user, null, self::CANH_BAO_ACS_KHONG_PHAN_HOI)
                : KetQuaDangNhap::thatBai();
        }
    }

    private function acs()
    {
        if ($this->acs === null) {
            $this->acs = new AcsAuthenticator();
        }

        return $this->acs;
    }

    private function acsEnabled()
    {
        return $this->acsEnabled === null ? (bool) config('auth.acs_enabled', false) : (bool) $this->acsEnabled;
    }

    private function timUser()
    {
        if ($this->timUser === null) {
            $this->timUser = function ($loginname) {
                return CustomUser::whereRaw('LOWER(loginname) = ?', [strtolower($loginname)])
                    ->where('is_active', 1)
                    ->first();
            };
        }

        return $this->timUser;
    }
}

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use App\Services\Auth\AcsSessionToken;
use App\Services\Auth\DangNhapService;
use Illuminate\Foundation\Auth\AuthenticatesUsers;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class LoginController extends Controller
{
    /*
    |--------------------------------------------------------------------------
    | Login Controller
    |--------------------------------------------------------------------------
    |
    | User qlbv la ACS_RS.acs_user (App\CustomUser). Quyet dinh dang nhap nam o DangNhapService;
    | controller chi lo throttle, Auth::login, regenerate session, luu TokenCode va canh bao.
    | Spec: docs/superpowers/specs/2026-09-22-van-ban-cong-khai-qr-design.md muc 5.
    |
    */

    use AuthenticatesUsers;

    /** Doc tu config trong __construct; ThrottlesLogins dung property_exists nen phai khai bao san. */
    protected $maxAttempts = 5;
    protected $decayMinutes = 1;

    /**
     * Where to redirect users after login.
     *
     * @var string
     */
    protected $redirectTo = '/home';

    public function __construct()
    {
        \Cookie::queue('remember', \Request::get('remember'));
        $this->middleware('guest')->except('logout');

        $this->maxAttempts = (int) config('auth.login_max_attempts', 5);
        $this->decayMinutes = (int) config('auth.login_decay_minutes', 1);
    }

    public function login(Request $request)
    {
        if (config('auth.providers.users.model') == 'App\User') {
            return $this->defaultLogin($request);
        }

        $this->validateLogin($request);

        // Chan TRUOC moi truy van/loi goi ACS: khong de man login qlbv thanh cong cu do
        // mat khau HIS hoac lam khoa tai khoan HIS.
        if ($this->hasTooManyLoginAttempts($request)) {
            $this->fireLockoutEvent($request);

            return $this->sendLockoutResponse($request);
        }

        $ketQua = app(DangNhapService::class)->xacThuc(
            strtolower($request->get('email')),
            $request->get('password')
        );

        if (!$ketQua->laThanhCong()) {
            $this->incrementLoginAttempts($request);

            return $this->sendFailedLoginResponse($request);
        }

        Auth::login($ketQua->user());
        $request->session()->regenerate();
        $this->clearLoginAttempts($request);

        if ($ketQua->token()) {
            (new AcsSessionToken($request->session()))->store($ketQua->token());
        }

        if ($ketQua->canhBao()) {
            $request->session()->flash('canh_bao_dang_nhap', $ketQua->canhBao());
        }

        return redirect()->intended($this->redirectPath());
    }

    protected function defaultLogin(Request $request)
    {
        $this->validateLogin($request);

        if ($this->attemptLogin($request)) {
            return $this->sendLoginResponse($request);
        }

        return $this->sendFailedLoginResponse($request);
    }

    protected function validateLogin(Request $request)
    {
        $request->validate([
            'email' => 'required|string',
            'password' => 'required|string',
        ]);
    }
}
